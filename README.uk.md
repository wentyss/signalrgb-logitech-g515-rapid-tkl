# Logitech G515 RAPID TKL для SignalRGB

Неофіційний плагін SignalRGB для окремого керування RGB-підсвіткою клавіш дротової Logitech G515 RAPID TKL. Перепрошивання не потрібне.

## Сумісність

Перевірено на одній G515 RAPID TKL з USB VID/PID **046D:C363**, HID-інтерфейсом 2 та розкладкою з 87 клавішами, високим Enter, довгим лівим Shift і клавішею зворотної скісної риски поруч з Enter. Інші розкладки, версії прошивки та моделі G515 не перевірялися. Індекси функцій HID++ наразі зафіксовані для перевіреного пристрою.

## Можливості

- Окрема підсвітка Canvas для всіх 87 клавіш.
- Режим Forced Color для одного кольору на всій клавіатурі.
- Вбудований у SignalRGB повзунок Device Brightness працює в обох режимах.
- Налаштовуваний Shutdown Color; використовуйте `#000000`, щоб вимикати підсвітку при штатному виході.
- Пропуск незмінених кольорів, заповнення діапазонів і оновлення 5-бітними дельтами, коли це зменшує обсяг передачі.
- Зіставлення відповідей HID++, виявлення Busy та інших помилок і відновлення абсолютними кольорами після непідтверджених оновлень.
- Повторне USB-підключення та перехід Windows у сон і вихід із нього успішно перевірено на конфігурації, використаній для розробки.

## Установлення

### Рекомендовано: додати цей репозиторій у SignalRGB

1. Відкрийте **SignalRGB → Settings → Plugins** і виберіть **Add Plugin Repository** (назви розділів можуть відрізнятися залежно від версії).
2. Додайте URL репозиторію:

   https://github.com/wentyss/signalrgb-logitech-g515-rapid-tkl

3. Якщо з’явиться запит, увімкніть репозиторій, дочекайтеся завантаження його плагінів, потім перезавантажте плагіни або перезапустіть SignalRGB.
4. Виберіть клавіатуру та **Lighting Mode → Canvas** або **Forced**.
5. Якщо залишаєте G HUB відкритим, виконайте наведені нижче інструкції спільної роботи. Windows Dynamic Lighting для цієї клавіатури має залишатися вимкненим.

При переході з ручного встановлення спочатку приберіть старий `G515_Rapid_TKL.js` із папки користувацьких плагінів. Не завантажуйте одночасно копію, встановлену вручну, і копію з репозиторію.

### Альтернатива: установлення вручну

1. Завантажте `G515_Rapid_TKL.js` зі сторінки файлу в цьому репозиторії.
2. Скопіюйте його в папку користувацьких плагінів SignalRGB, зазвичай `%USERPROFILE%\Documents\WhirlwindFX\Plugins`.
3. Перезапустіть SignalRGB, якщо він не перезавантажить плагін автоматично.

## Використання G HUB разом із SignalRGB

Наведену конфігурацію перевірено на клавіатурі, використаній для розробки, зокрема зі зміною налаштувань спрацювання в G HUB та виходом Windows зі сну:

1. У **Параметри Windows → Персоналізація → Динамічне освітлення** вимкніть Dynamic Lighting для цієї клавіатури. Якщо окреме керування пристроєм недоступне, глобально вимкніть **Використовувати динамічне освітлення на моїх пристроях**.
2. У G HUB виберіть клавіатуру та встановіть **LIGHTSYNC → Presets → Off**. Це рекомендовано для зменшення кольорових спалахів під час запуску SignalRGB або відновлення його роботи. Це не гарантує усунення всього миготіння під час запуску або пробудження: підсвітка з пам’яті клавіатури може з’явитися до того, як будь-яка з програм отримає керування. Після цього залиште G HUB відкритим для налаштування клавіатури та інших пристроїв Logitech.
3. Якщо SignalRGB повідомляє про конфлікт із **Logitech G HUB**, виберіть опцію **ігнорування цього конфлікту**, щоб SignalRGB продовжив керувати клавіатурою.
4. Перезапустіть SignalRGB, якщо він уже припинив керувати клавіатурою, потім виберіть режим **Canvas** або **Forced**.
5. Переконайтеся, що підсвітка продовжує реагувати на зміни, коли G HUB відкритий.

**Залишайте Windows Dynamic Lighting вимкненим.** Його ввімкнення через опцію **WINDOWS SETTINGS** у G HUB і встановлення пріоритету SignalRGB у Windows спочатку здавалися робочим рішенням, але згодом спричинили завмирання підсвітки й оновлення приблизно раз на десять секунд. Вимкнення Dynamic Lighting відновило нормальну роботу.

Із вимкненим Windows Dynamic Lighting та ігноруванням конфлікту G HUB у SignalRGB підсвітка залишалася активною під час використання G HUB і після переходу в сон та виходу з нього на перевіреній конфігурації. Під час пробудження спостерігалося коротке миготіння підсвітки всього ПК до завершення ініціалізації SignalRGB; постійне миготіння або завмирання після цього не є очікуваним.

Це результат однієї перевіреної конфігурації, а не гарантія для всіх версій програмного забезпечення чи прошивки. Якщо програми починають конкурувати за підсвітку або вона завмирає, повністю закрийте G HUB, переконайтеся, що Dynamic Lighting вимкнене, і перезапустіть SignalRGB. Після вибору Off керуйте підсвіткою через SignalRGB, а рештою налаштувань — через G HUB. Подальші одночасні зміни LIGHTSYNC не перевірялися.

## Елементи керування

| Налаштування | Поведінка |
|---|---|
| Lighting Mode | Ефект Canvas або Forced Color |
| Forced Color | Колір, який використовується в режимі Forced |
| Device Brightness | Загальна яскравість у Canvas і Forced |
| Shutdown Color | Колір при штатному завершенні роботи плагіна, незалежний від Device Brightness |

Повзунок яскравості всередині палітри Forced Color змінює сам вибраний колір. Потім Device Brightness масштабує його яскравість.

## Відомі обмеження

Швидкі просторові градієнти обмежені пропускною здатністю передачі USB-команд. Вимірювання під час розробки до остаточних змін обробки відповідей становили приблизно 9–10 кадрів/с для швидкого градієнта, 14 кадрів/с для повільнішого градієнта з дельтами та 24 кадри/с для ефекту зі спільним кольором. Це спостереження для конкретних ефектів, а не гарантовані показники продуктивності фінальної версії.

Плагін періодично оновлює абсолютні кольори, щоб обмежувати накопичення розбіжностей стану. Він не налаштовує Rapid Trigger, точки спрацювання, аналоговий ввід або макроси клавіатури. Застосування Shutdown Color не гарантоване після аварійного завершення, втрати живлення або від’єднання USB. Клавіатура може коротко відображати профіль із власної пам’яті до того, як SignalRGB отримає керування.

## Усунення несправностей і повідомлення про проблеми

`RGB HID++ replies confirmed` записується в журнал один раз після підтвердження кадру. Повторювані повідомлення `Busy`, тайм-ауту відповіді або помилок запису вказують на проблему, яка потребує дослідження.

Створюючи [issue](https://github.com/wentyss/signalrgb-logitech-g515-rapid-tkl/issues), вкажіть версію SignalRGB, версію прошивки за наявності, USB VID/PID, розкладку клавіатури, кроки відтворення та відповідні повідомлення Device Console. Перед публікацією перевірте скриншоти й записи трафіку на наявність особистої інформації.
